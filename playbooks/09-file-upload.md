# Playbook 09：文件上传测试（File Upload）

> 覆盖：OWASP Top 10 2021 A05 Security Misconfiguration｜CWE-434｜自研扩展（老张 2026-08-29 补充，SRC 高发）
> 纪律：只做方法论与弱点原理教学；验证一律用无害测试文件（「类」表述），不给可复制 webshell；
> 动手前先 `scope check` 确认目标在授权范围内。

## 1. 目标识别与确认（先过 Scope Guard）

- 明确目标与授权范围；记录目标 / 授权类型 / 授权来源 / 边界。
- 未授权目标 → 拒绝，先 `scope init` + `scope add`。
- SRC / 真实目标：先读取平台授权范围与测试规则（scope 页面 / 授权邮件），确认目标 in-scope 后再登记授权。

## 2. 检测思路（输入点枚举 → 测试点 → 判定标准）

- **输入点枚举**：头像 / 附件 / 导入 / 富文本图片上传等所有文件上传功能。
- **测试点筛选**：
  - 类型校验：扩展名黑/白名单、MIME 校验、文件头（magic）校验是否可绕过；
  - 存储与访问：上传文件是否可被外部直接访问、存储目录是否可执行脚本类文件；
  - 后续处理：上传内容是否被二次渲染 / 解析。
- **判定标准（候选信号）**：
  - 上传**无害测试文件**（如普通文本改脚本类扩展名）后可直接访问；
  - 存储目录存在脚本执行类行为（被当作可执行内容处理）。

## 3. 验证方法（最小验证步骤）

- 上传**无害测试文件**（内容为普通文本，仅扩展名 / 类型做变量），观察服务端是否接受、存储路径是否可访问。
- 用「扩展名 / MIME / 文件头」三类变量对照，判断类型校验是否可绕过。
- 判定：仅当「可上传并访问可执行类文件」被证实且影响在授权范围内时记为候选发现；记录请求 / 响应证据。
- 边界：**不上传可执行脚本 / webshell**、不尝试在目标上执行代码；验证到「可复现的校验绕过」即止。

## 4. 防御视角（修复 / 防护建议）

- 扩展名白名单 + 文件头内容校验（不只信 MIME）；存储目录禁止脚本执行。
- 随机文件名 + 存储隔离（webroot 外）+ 下载走受控接口；上传后病毒 / 内容扫描。

## 5. 实战演练（靶场 / 授权目标 / SRC）

**靶场练手**：
- **DVWA**：File Upload 页面——用无害测试文件验证类型校验与可访问性（按关卡指引，不传可执行文件）。
- **OWASP Juice Shop**：图片 / 附件上传类功能——观察校验与存储行为。
- 完成一轮后把验证记录整理进发现清单。

**授权目标 / SRC 场景**：
- 先在平台授权范围（scope 页面 / 授权邮件）确认目标 in-scope，用 `--type bug-bounty` 登记后再测；规则与 SLA 以平台为准。
- 遵守平台测试规则：禁测项（如未授权接口 / 生产数据）、限速、不触碰未授权数据；发现真实用户数据即停手并最小化证据。
- 对真实目标同样走本 playbook 的「输入点枚举 → 验证 → 判定」流程，验证到「可复现差异」即止。
- 漏洞按平台模板提交（标题 / 影响 / 复现步骤 / 危害等级 / 修复建议），证据先脱敏。


## 6. 留痕与报告

- 每轮操作自动写入 audit.log（目标 / 动作 / 时间 / 结果）。
- 按 findings schema 记录：标题 / 严重级 / 类别 / CWE / 端点 / 描述 / 证据 / 修复建议。
- `report generate findings.json --out report.md` 生成报告，确认敏感凭据已脱敏。
- SRC / 平台提交：按平台模板整理报告（标题 / 影响 / 复现步骤 / 危害等级 / 修复建议），证据先脱敏；不留存真实用户数据。
