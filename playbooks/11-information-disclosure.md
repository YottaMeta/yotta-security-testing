# Playbook 11：敏感信息泄露测试（Information Disclosure）

> 覆盖：OWASP Top 10 2021 A05 Security Misconfiguration（信息泄露）｜自研扩展（老张 2026-08-29 补充，SRC 高发）
> 纪律：只做方法论与弱点原理教学；验证「类」表述，不批量拉取、不留存真实敏感数据；
> 动手前先 `scope check` 确认目标在授权范围内。

## 1. 目标识别与确认（先过 Scope Guard）

- 明确目标与授权范围；记录目标 / 授权类型 / 授权来源 / 边界。
- 未授权目标 → 拒绝，先 `scope init` + `scope add`。
- SRC / 真实目标：先读取平台授权范围与测试规则（scope 页面 / 授权邮件），确认目标 in-scope 后再登记授权。

## 2. 检测思路（输入点枚举 → 测试点 → 判定标准）

- **输入点枚举**：备份 / 源码 / 配置文件类路径、调试接口、报错信息、响应头、目录列举、前端源码地图。
- **测试点筛选**：
  - 常见敏感路径类（备份 / 源码 / 配置 / 数据库导出类）；
  - 错误处理（异常是否回显堆栈 / 内部路径 / 数据库信息）；
  - 响应头与前端资源（是否泄露版本 / 内部信息 / 源码地图）。
- **判定标准（候选信号）**：
  - 未授权可访问敏感文件或接口内容；
  - 报错 / 响应头泄露内部实现细节。

## 3. 验证方法（最小验证步骤）

- 用「常见敏感路径类」做最小探测（少量、明确记录在案），观察是否可未授权访问。
- 触发一次可控错误，观察报错是否回显内部信息；检查关键响应头与前端源码地图。
- 判定：仅当「敏感信息可被未授权获取」被证实且影响在授权范围内时记为候选发现；记录请求 / 响应证据。
- 边界：不批量拉取敏感文件、不留存真实用户 / 凭据数据；验证到「可复现的泄露」即止。

## 4. 防御视角（修复 / 防护建议）

- 敏感文件（备份 / 源码 / 配置 / 导出）不进可公开访问目录；目录列举关闭。
- 生产环境关闭调试信息与详细报错；安全响应头（版本隐藏 / 信息最小化）；源码地图按需发布。

## 5. 实战演练（靶场 / 授权目标 / SRC）

**靶场练手**：
- **OWASP Juice Shop**：敏感信息 / 报错类关卡——枚举常见路径与报错行为（按关卡指引）。
- **DVWA**：无内置信息泄露关卡，可自建本地小应用演练（本地靶机需先授权）。
- 完成一轮后把验证记录整理进发现清单。

**授权目标 / SRC 场景**：
- 先在平台授权范围（scope 页面 / 授权邮件）确认目标 in-scope，用 `--type bug-bounty` 登记后再测；规则与 SLA 以平台为准。
- 遵守平台测试规则：禁测项（如未授权接口 / 生产数据）、限速、不触碰未授权数据；发现真实用户数据即停手并最小化证据。
- 对真实目标同样走本 playbook 的「输入点枚举 → 验证 → 判定」流程，验证到「可复现差异」即止。
- 漏洞按平台模板提交（标题 / 影响 / 复现步骤 / 危害等级 / 修复建议），证据先脱敏。


## 6. 留痕与报告

- 每轮操作自动写入 audit.log（目标 / 动作 / 时间 / 结果）。
- 按 findings schema 记录：标题 / 严重级 / 类别 / CWE / 端点 / 描述 / 证据 / 修复建议。
- `report generate findings.json --out report.md` 生成报告，确认敏感凭据已脱敏。
- SRC / 平台提交：按平台模板整理报告（标题 / 影响 / 复现步骤 / 危害等级 / 修复建议），证据先脱敏；不留存真实用户数据。
